An original round-based tactical FPS built for the **make.fun three.js FPS bounty** ($1,000). First to 5 rounds — you + 2 bot teammates vs 4 raider bots. Win rounds by elimination or by capturing Sector C. Earn money, buy better guns between rounds. three.js 0.187.0 vendored, static files, no build step, no network requests.

## Run it

Serve `game/` with any static server, then open it in desktop Chrome:

```sh
python3 -m http.server -d game 8080
# then open http://localhost:8080
```

WASD move · mouse aim · click fire · R reload · G grenade · Ctrl crouch · B buy menu · P pause
